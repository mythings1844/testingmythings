# 🧢 Sneakers and More

¡Bienvenido a **Sneakers and More**! Este es un sitio web personal diseñado para mostrar y organizar colecciones de zapatillas, gorras y otros artículos exclusivos, incluyendo un sistema de filtrado en tiempo real por marca, modelo o código SKU.

## 🚀 Enlace en vivo
Puedes visitar el sitio web desplegado en internet a través de GitHub Pages:
👉 [https://mythings1844.github.io/testingmythings/](https://mythings1844.github.io/testingmythings/)

---

## 📂 Estructura del Proyecto

El repositorio está organizado con las siguientes páginas principales:

* **`index.html`**: Página de inicio (Home) con la presentación principal del sitio.
* **`Store.html`**: Catálogo completo de la colección de zapatillas.
* **`Sold.html`**: Sección dedicada a los artículos vendidos o de salida.
* **`Others.html`**: Categoría de accesorios y otros artículos (como gorras de *New Era*, etc.) con buscador integrado.
* **`website_homepage.htm`**: Sección de lista de deseos (*Wish list*).
* **`Imagenes/`**: Carpeta contenedora de todos los recursos gráficos (fotografías de productos, fondos y favicons).

---

## 🛠️ Tecnologías Utilizadas

* **HTML5**: Estructura semántica de las páginas web.
* **CSS3**: Estilos personalizados, diseño adaptable (*Responsive Design*) mediante Grid/Flexbox y paleta de colores moderna.
* **JavaScript (Vanilla)**: Lógica para el filtrado dinámico e instantáneo de productos en tiempo real.
* **Git y GitHub**: Control de versiones y alojamiento web.

---

## 🌐 ¿Cómo está montado con GitHub Pages?

El proyecto utiliza **GitHub Pages** para su despliegue y alojamiento gratuito directamente desde el repositorio:

1. **Alojamiento estático:** Al tratarse de una web desarrollada puramente con tecnologías frontend (HTML, CSS y JS), GitHub Pages sirve los archivos estáticos de forma directa sin necesidad de un servidor backend externo.
2. **Rama de despliegue:** La configuración apunta a la rama principal (`main`) en la raíz del repositorio (`/root`), tomando el archivo `index.html` como la página de entrada principal.
3. **Integración continua:** Cada vez que se realizan cambios locales y se suben al repositorio mediante Git (`git push origin main`), GitHub Pages actualiza automáticamente el sitio web en vivo en pocos minutos sin requerir configuraciones de despliegue manuales adicionales.

---

## 📱 Características de Diseño

* **Diseño Responsivo:** Adaptado de forma fluida tanto para ordenadores como para dispositivos móviles (con menús en columna y ajuste automático de elementos en pantallas pequeñas).
* **Buscador Dinámico:** Filtrado instantáneo por texto que oculta o muestra categorías y tarjetas según la búsqueda del usuario.
* **Estética Minimalista:** Uso de tipografías modernas (*Inter* de Google Fonts) y tarjetas con efectos visuales uniformes.
